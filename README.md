# STD-AI
You can download the AI HTML from them.
STD 的 AI 学习站 · 公开 HTML 版

本项目由 STD 提供核心思路与安全架构，AI 辅助编写代码，经过约 31 次版本迭代完成的纯前端综合性工具站。所有代码开源，无需后端服务器，开箱即用。

🌟 核心功能模块

1. 🧭 极简导航页
   · 聚合必应、百度、谷歌等主流搜索引擎。
   · 快捷跳转 B站、知乎、GitHub 等常用网站（带安全跳转确认）。
2. 🧰 实用工具箱（15+ 工具）
   · 时间管理：全屏时钟、精准秒表、番茄钟、倒计时。
   · 日常辅助：本地便签、随机抽签、字数统计、二维码生成。
   · 计算工具：颜色取色器、BMI 计算、密码生成器、单位换算。
   · 专注环境：基于 Web Audio API 生成的白/粉/棕噪音。
3. ✍️ AI 卷制作系统
   · 支持拖拽导入 .docx、.txt、.json 等多种文本/文档格式。
   · 自动解析并排版为 A4 试卷样式，支持一键导出为图片。
   · 内置安全机制：拒绝解析含有数字签名、加密保护、PDF 和图片等可能涉及版权风险的文件。
4. 📸 AI 阅卷批改系统
   · 上传试卷图片，点击标记打分坐标。
   · 一键复制坐标与提示词发给 AI，粘贴 AI 返回的 JSON 结果后，一键在图片上渲染出“✔”或“✘ 错因”。
   · 自动添加 AI 显式水印，符合生成式 AI 内容标识要求。

🛡️ 隐私与安全合规

· 纯前端架构：所有文件解析、数据计算、图片渲染均在你的本地浏览器完成，绝不向服务器上传任何隐私数据。
· 严格免责协议：内置用户使用与合规免责协议弹窗，明确禁止商业用途、教育培训经营活动，并界定 AI 生成内容仅供参考。
· XSS 防御：内置 safeRender 函数，对导入的文本和 HTML 进行严格的标签与属性过滤。
